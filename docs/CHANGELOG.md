- **중앙도서관 잔여석 수정:** 학교 API의 `available`은 사용 중인 자리까지 포함한 값이어서 잔여석이 실제보다 많게 표시되었습니다. 학교 좌석 페이지와 같은 계산식으로 바꿨습니다.

- **사용률·혼잡도 기준 변경:** `사용 중 ÷ 실제 이용 가능 좌석`으로 학교 페이지와 맞췄습니다.

- **브라우저 알림:** 개인 사용 화면에서 켜 두면 다른 탭이나 앱을 보고 있을 때 같은 내용을 알려 줍니다.

## 2026년 11월 13일

### 1. 📍 "가장 가까운 열람실"을 지도로 찾아 줘요 (개인 사용 화면)

시험기간엔 어디가 비었는지보다 **어디가 가까운지**가 더 궁금하죠. 휴대폰 화면에서 버튼 하나로 알려 줍니다.

```
┌───────────────────────────────────┐
│ 📍 가까운 열람실            [다시 찾기] │
│ ┌───────────────────────────────┐ │
│ │ 빈자리가 있는 가장 가까운 곳         │ │
│ │ 열람실 A · 5강의동 5102호         │ │
│ │ 직선 약 100m · 걸어서 약 1분 · 28석 │ │
│ │ [좌석 보기]   [카카오맵 길찾기]      │ │
│ └───────────────────────────────┘ │
│ ┌───────── 🗺️ 카카오 지도 ─────────┐ │
│ │   (중앙도서관 · 421석)            │ │
│ │        ● 내 위치                  │ │
│ │   (열람실 A · 28석)  (열람실 B · 30석) │ │
│ └───────────────────────────────┘ │
│ 중앙도서관   약 90m · 빈자리 421석 [길찾기] │
│ 열람실 A     약 100m · 빈자리 28석  [길찾기] │
└───────────────────────────────────┘
```

- **[내 위치로 가까운 열람실 찾기]** 를 누르면 그때 위치를 묻습니다. (화면을 열자마자 묻지 않아요.)
- 예비 열람실 **A · B · C** 와 **중앙도서관** 중에서 **빈자리가 있는** 가장 가까운 곳을 추천합니다. 만석인 곳은 건너뛰어요.
- **카카오 지도**에 내 위치와 각 장소의 빈자리 수가 표시되고, **[카카오맵 길찾기]** 를 누르면 걸어가는 길을 안내받을 수 있어요.
- 🔐 위치는 **휴대폰 안에서 거리 계산에만** 쓰고 서버로 보내지 않습니다.
- 거리는 직선거리 기준의 어림값이에요. 실제 길은 카카오맵 길찾기로 확인하세요.
- 건물 위치는 **카카오 장소 검색**으로 확인했습니다 (수원캠퍼스 31곳 중 30곳).
- ⚠️ 지금은 **휴대폰 브라우저**에서 동작합니다. 안드로이드 앱 안에서의 위치 기능은 앱 작업 때 이어서 합니다.

### 2. 🏫 관리자는 강의실 위치를 "고르기 + 숫자 키패드"로 입력해요

예전엔 강의실 위치를 글자로 직접 적었는데, 사람마다 "제5강의동", "5강의동 덕문관"처럼 다르게 쓰게 되더라고요.

- **건물**은 목록에서 고릅니다 — 1강의동 진리관 ~ 9강의동 호연관, 종합강의동, 제2공학관, 중앙도서관 등 **수원캠퍼스 31곳**.
- **호실**은 칸을 누르면 화면에 **숫자 키패드**(0~9 · ⌫ · 확인)가 떠요. 숫자만, 5자리까지.
- 학생 화면에는 **"5강의동 4405호"** 처럼 깔끔하게 보이고, 위 지도 기능도 이 위치로 열람실을 찾아요.
- 예전에 직접 적어 둔 값("제 5강의동 5102호" 등)도 알아서 읽어 들입니다.

### 3. 🧭 화면 맨 위에서 [개인 사용 | 키오스크 | 관리자] 로 바로 이동

- 세 화면 모두 **맨 위 한 줄**에서 바로 오갈 수 있어요. 예전엔 관리자 화면 링크가 화면 맨 아래에 숨어 있었습니다.
- 화면마다 주소가 따로 있어서, **입구 기기는 `…/#/kiosk` 를 즐겨찾기**로 열어 두면 늘 키오스크 화면으로 열려요.
- 앱 안에서는 개인 사용 화면만 보이고, 이 줄은 숨겨집니다.

### 4. 🩺 서버 상태 점검은 필요할 때만

- 장치 연결 · 와이파이 · 학교 도서관 서버 상태를 보여 주던 표시줄을 **화면 맨 아래 [서버 상태 점검] 버튼** 뒤로 숨겼어요.
- 누를 때만 보이고, **숨겨져 있는 동안엔 서버에 상태를 묻지 않아서** 불필요한 요청도 줄었습니다.

### 5. 🎨 그 밖에

- 화면 왼쪽 위 로고와 **브라우저 탭 아이콘**을 **경기대학교 로고**로 바꿨어요.
- (개발) **키오스크 · 개인 사용 · 관리자 화면의 코드를 완전히 따로** 나눴어요. 한 화면을 고쳐도 다른 화면이 망가지지 않도록 하기 위해서예요.
  공통으로 쓰는 건 서버와 주고받는 부분뿐입니다.

### ✅ 바뀌지 않은 것

- 예약을 최종 승인하는 곳은 여전히 **서버(장부) 한 곳**뿐이고, 한 사람 한 자리 · 15분 자동 취소 · 로그인 방식도 그대로예요.
- 이번 변경은 모두 **화면(웹)** 쪽이라 서버 · 데이터베이스 · 앱은 바뀌지 않았습니다.

- **좌석 번호와 개수는 그대로**이고 위치만 바뀝니다. 사용 중인 좌석을 옮겨도 예약에는 영향이 없어요.
- 두 관리자가 동시에 편집하면, 나중에 저장한 사람에게 "다른 관리자가 먼저 바꿨습니다"라고 알려 **서로 덮어쓰지 않습니다.**

### 2. 🖥️ PC 화면이 넓게 보여요

예전엔 PC로 열어도 가운데에 휴대폰 크기 화면만 보였습니다. 이제 **화면 폭에 맞춰 자동으로** 바뀝니다.

```
┌───────────────────────────────────────────────────────────────┐
│ KGU 열람실 좌석      [좌석] [중앙도서관] [내 이용]   [개인|키오스크] 🟢 │
├────────────────────────────────────┬──────────────────────────┤
│  [열람실 A] [열람실 B] [열람실 C]      │  ┌── 내 상태 ───────────┐  │
│  🚪 [   칠판 · 교탁   ]               │  │ A20 좌석 · 59:59      │  │
│  A01 A02 A03     A04 A05 A06   🪟   │  │ [퇴실하기] [내 자리]   │  │
│  A07 A08 A09     A10 A11 A12   🪟   │  └─────────────────────┘  │
│  ... (크게 보이는 배치도)              │  📚 중앙도서관 잔여 421석   │
└────────────────────────────────────┴──────────────────────────┘
```

- PC(폭 900px 이상): 탭은 상단 바에, 왼쪽은 큰 배치도, 오른쪽은 내 상태 카드 · 중앙도서관 요약. 좌석을 누르면 **가운데 창**이 떠요.
- 휴대폰·앱(좁은 화면): 지금까지의 모바일 화면 그대로입니다.

### 3. 👤 "개인 사용 / 키오스크" 모드가 생겼어요

**키오스크**는 열람실 입구에 놓여 **누구나 쓰는 공용 기기**입니다. 그런 기기에 개인용 기능이 보이는 건 맞지 않아서, 화면 상단에 모드 스위치를 달았습니다.

| | 👤 개인 사용 모드 | 🏫 키오스크 모드 |
|---|---|---|
| 언제 | **본인 휴대폰** (휴대폰으로 열면 기본값) | **입구의 공용 기기 · PC** (기본값) |
| 블루투스 좌석 자동 연장 | ✅ 보임 | ❌ 숨김 (켜져 있었다면 바로 끊김) |
| 자동 로그아웃 (90초 동안 안 쓰면) | 하지 않음 | ✅ 함 (다음 사람이 내 계정을 쓰지 않도록) |

- 바꾼 선택은 그 기기에 기억됩니다.
- 모바일 **앱**은 항상 본인 휴대폰이므로 개인 사용 모드로 고정되고, 스위치는 보이지 않아요.

### 4. 📶 앱 없이 **휴대폰 브라우저**만으로도 블루투스 자동 연장 (시험 단계)

지금까지는 블루투스 자동 연장을 쓰려면 안드로이드 앱이 필요했습니다. 이제 **휴대폰 브라우저**(Android의 Chrome · Edge · 삼성 인터넷)에서도 됩니다.

1. 개인 사용 모드에서 열람실 A 좌석에 착석
2. 상태 카드의 **[블루투스로 자리 확인 켜기]** → 기기 선택 창에서 `LIB-SEAT-PI` 선택 *(브라우저 보안 규칙상 처음 한 번은 직접 골라야 해요)*
3. 라즈베리파이가 응답하면 **"📶 블루투스로 자리 확인됨"** → 남은 시간이 2시간 아래로 줄지 않아요
4. 자리를 떠나 연결이 끊기면 "다시 연결하는 중", 돌아오면 자동으로 다시 연결

- 브라우저는 신호 세기를 알려 주지 않아서, **"연결되어 있고, 라즈베리파이가 25초 안에 응답한다"** 를 "자리에 있음"으로 판단합니다. 앱의 신호 세기 기준보다는 덜 정밀해요.
- 블루투스로는 확인 신호(`PING`) 말고는 **아무것도 보내지 않습니다** (학번·비밀번호 없음).
- ⚠️ **iPhone(Safari)과 Firefox는 브라우저 블루투스를 지원하지 않아** 안내만 보입니다.
- ⚠️ 화면을 켜 둔 동안만 동작합니다. 아직 **실제 라즈베리파이와는 시험 전**이고, 가짜 장치로 시험을 마친 상태입니다.

### 1. 📱 화면이 "휴대폰 앱처럼" 바뀌었어요

예전 화면은 표와 버튼이 나열된 관리용 화면에 가까웠습니다. 이제는 휴대폰에서 쓰기 편한 모양입니다.

```
┌──────────────────────────────┐
│ KGU 열람실 좌석   🟢실시간 [로그인] │  ← 맨 위: 연결 상태 · 내 계정
│┌────────────────────────────┐│
││ 예약 완료 · 열람실 A          ││  ← 파란 카드: 지금 내 상태가 한눈에
││ A05 좌석          착석까지 14:59 ││     (남은 시간이 1초씩 줄어요)
││ [착석했어요]  [예약 취소]       ││
│└────────────────────────────┘│
│  [열람실 A] [열람실 B] [열람실 C]  │  ← 열람실 고르기 (잔여 좌석 수 표시)
│  🚪출입구 [ 칠판 · 교탁 ] 창가→   │
│  A01 A02 A03   A04 A05 A06      │  ← 실제 강의실처럼 가운데 통로
│  ...                            │
│            뒤쪽                  │
├──────────────────────────────┤
│   💺좌석   🏛중앙도서관   👤내 이용  │  ← 아래 탭
└──────────────────────────────┘
```

- **좌석을 누르면 아래에서 창이 올라와요.** 그 자리 상태와 [예약하기] 버튼이 보입니다.
- **로그인도 같은 창에서.** 자리를 고른 뒤 로그인하면, 로그인이 끝나자마자 고른 자리로 돌아옵니다.
- **실수 방지:** [예약 취소]·[퇴실]은 "정말 할까요?"를 한 번 더 묻습니다.
- **알림 메시지**는 화면 위에 잠깐 떴다 사라집니다. (오류는 조금 더 오래 보여요.)
- **중앙도서관 탭:** 학교 도서관이 지금 **혼잡 / 보통 / 여유** 중 어디인지 색으로 보여주고,
  "중앙도서관이 거의 꽉 찼어요 → 열람실 A에 25자리 남았어요"처럼 대안을 바로 알려 줍니다.
- **아직 준비 중인 기능**(콘센트·창가 같은 좌석 조건 필터, 자주 앉던 자리 추천, 이용 통계·기록)은
  화면에 **"기능 추가 예정"** 이라고 솔직하게 표시해 두었습니다.

### 2. ⏰ 이용 시간을 고르고, 끝나면 자동 퇴실

- 착석할 때 **1 · 2 · 3 · 4시간** 중 이용 시간을 고릅니다.
- 화면에서 남은 시간이 계속 줄어드는 게 보이고, **시간이 다 되면 자동으로 퇴실**됩니다.
  퇴실 버튼을 깜빡해도 자리가 하루 종일 묶이지 않아요.
- 사용 중인 자리를 누르면 다른 학생도 "이 자리는 몇 시에 비는지"를 볼 수 있습니다. (누가 앉았는지는 보이지 않아요.)

### 3. 📶 앱을 켜 두면 "자리에 있는 동안" 시간이 자동으로 늘어나요 (시험 운영)

- 안드로이드 앱 **"도서관 좌석"** 이 생겼습니다. 앱을 열면 위 웹 화면이 그대로 나옵니다.
- 앱은 **블루투스로 열람실 A의 라즈베리파이 신호**가 잡히는지 확인합니다.
  신호가 잡히면 = 열람실 안에 있다는 뜻이므로, **남은 시간이 2시간 아래로 내려가지 않게** 자동으로 채워 줍니다.
- 열람실을 떠나면 더 이상 늘어나지 않고, 고른 시간이 끝나면 자동 퇴실됩니다.
- 🔐 서버에는 "마지막으로 열람실 안에 있었던 시각" **하나만** 저장합니다. 이동 경로나 위치 기록은 남기지 않고,
  휴대폰 이름이나 전체 기기 주소도 보내지 않습니다.
- ⚠️ 아직은 **열람실 A만**, **앱 화면을 켜 둔 동안만** 동작하는 시험 단계입니다.
  또 앱이 보내는 신호를 서버가 그대로 믿는 구조라, 마음먹고 조작하면 속일 수 있다는 한계가 있습니다 (문서에 기록해 두었어요).

### 4. 🏫 강의실 호수 표시 · 강의실 모양 배치도

- 관리자가 관리자 화면에서 각 열람실의 **강의실 호수**(예: "제2공학관 401호")를 입력할 수 있습니다.
  저장하는 즉시 모든 학생 화면의 배치도 위, 좌석 상세 창, 예약 카드에 표시됩니다. (비워 두면 "열람실 A"로 표시)
- 좌석 배치도가 단순한 격자에서 **실제 강의실 모양**으로 바뀌었습니다.
  앞쪽에 출입구·칠판(교탁)·창가, **3석 + 가운데 통로 + 3석**, 맨 뒤에 "뒤쪽" 표시.
  > 출입구·창가 위치는 지금은 임시 배치입니다. 실제 강의실 구조가 확정되면 맞춰 바꿉니다.

### 5. 🔧 그 밖에

- 관리자 화면에 **라즈베리파이 원격 끄기** 버튼이 생겼습니다. (두 번 확인을 받아야 꺼져요.)
- 시연 기간 동안 관리자 로그인 화면에 **테스트 관리자 계정**이 표시됩니다. 시연이 끝나면 끄고 비밀번호를 바꿉니다.
- 라즈베리파이와 휴대폰 사이의 **블루투스 통신**을 단계별로 만들고 시험했습니다.
  (연결 · 신호 세기 측정 · 메시지 주고받기 · 끊기면 자동 재연결 · 장시간 안정성 시험)

### ✅ 바뀌지 않은 것 (안심하세요)

- 예약을 최종 승인하는 곳은 여전히 **서버(장부) 한 곳**뿐입니다. 화면이나 앱이 혼자 예약을 확정하지 않아요.
- **한 사람 한 자리**, **동시에 눌러도 한 명만**, **15분 안에 착석 안 하면 자동 취소** 규칙은 그대로입니다.
- 로그인 방식(학번 + 비밀번호)도 바뀌지 않았습니다.
